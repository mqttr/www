By far among the projects that I am most happy with and proud of is my homelab. All of the services listed below are running on an Old Dell Optiplex in the corner of my room. It uses a hardened Docker Compose set up. It is designed in such a way where I can copy the files over from that machine to almost any other machine and host my entire homelab from that new device seamlessly.

Services

  • Caddy (reference)
    • using Cloudflare & Cloudflared tunnel
  • pocket-id (reference)
    • unifies login management among unrelated services
  • Forgejo (reference)
    • supports pushing via SSH over a Cloudflared tunnel
    • hosts OCI images including the one for this website
    • automatically builds OCI images using Forgejo Actions on tag and branch pushes
